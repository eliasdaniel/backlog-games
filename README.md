# Backlog de Videojuegos

CRUD para gestionar mi backlog personal de videojuegos.
Permite agregar, listar, editar y eliminar juegos, con filtros por
estado, género y búsqueda por título.

## Tecnologías
- Node.js + Express
- MongoDB 
- HTML, CSS y JavaScript
